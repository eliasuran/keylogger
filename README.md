basic keylogger, stores key pressed in a log file. captures keys pressed even if program is in the background

## built w/

python3 (uv), pyobjc

## requirements

- uv
- python3

## build

1. clone git repo (`git clone https://github.com/eliasuran/keylogger.git`)
2. run designated build script

**windows**

```
.\build.ps1
```


**mac/linux**

```
./build.sh
```


## run the program

**windows**

```
.\keylogger
```

**mac/linux**

```
./keylogger
```
